Executive Summary
This document outlines the complete architectural schema for Divine Fingers Healthcare Services Inc. The system transitioned from an insecure, client-side localStorage prototype to a production-grade Node.js (Express) + MySQL backend. Key features include real-time dispatch via Server-Sent Events (SSE), role-based JWT authentication, rate limiting, and PHIPA/PIPEDA-compliant candidate resume handling.

1. High-Level Architecture & Deployment Topology

The system operates on a decoupled, secure hybrid architecture (Option B) designed for high reliability, fast global delivery, and data isolation:

Frontend Layer (Vercel Edge)

Multi-Page Static Application served across global Edge CDN nodes for minimal latency and 100% uptime.

  • HTML5 / CSS3 (Design System)
  • GSAP ScrollTrigger Animation Engine
  • EventSource Real-Time Listener
  • Asynchronous Multipart Form Handlers
Backend & Database (Hostinger)

Hardened Node.js Express REST API paired with a localized MySQL 8.0+ relational database engine.

  • Node.js 20.x LTS + Express.js
  • MySQL 8.0 (InnoDB utf8mb4)
  • JWT RBAC & Bcrypt (Cost 12)
  • Protected Disk Storage (chmod 700)

3. Backend Architecture & REST API Endpoints

The Express.js backend layer orchestrates security, data validation, rate limiting, and real-time broadcasting:

Method Endpoint Authorization Description & Security Validation
POST /api/requests Public (Limiter) Zod validation. Inserts shift order into staffing_requests, triggers email alert, broadcasts SSE.
POST /api/applications Public (Limiter) Multipart upload via Multer. Enforces PDF/DOCX MIME type and 10MB limit. Stores file to protected disk.
POST /api/contact Public (Limiter) Validates inquiry data and writes to contact_inquiries table.
POST /api/auth/login Public (Strict) Bcrypt compare. Limits 5 failed attempts per 15 min; locks account and logs audit; issues signed JWT.
GET /api/admin/stream JWT Required Server-Sent Events (SSE) stream providing instant real-time updates to connected admin clients.
GET /api/admin/requests JWT Required Returns all facility requests with joined staff roster names sorted by recency.
PATCH /api/admin/requests/:id/status JWT Required Updates request status & assigned nurse; writes record into immutable audit_logs table.
GET /api/admin/applications JWT Required Fetches recruitment pipeline entries.
GET /api/admin/applications/:id/resume JWT Required Securely streams candidate resume file from protected storage directory to authorized admin.
GET /api/admin/roster JWT Required Retrieves active agency nurse & PSW records.
GET /api/admin/audit-logs JWT Required Retrieves last 100 immutable administrative audit log entries.
GET /api/health Public System liveness check.
